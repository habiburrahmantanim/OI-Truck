## 4. Architecture

### 4.1 Provider tree — `frontend/app/layout.tsx`
```
<html><body>
  AuthProvider
    TruckProvider
      DriverProvider
        BookingProvider
          {children}
          <Footer />      <-- Footer is global; Navbar is NOT (per-page)
```
Metadata: title "OI-Truck | Truck Lagbe".

### 4.2 State: 4 Contexts (all `"use client"`, all localStorage-backed)

| Context | Hook(s) | localStorage key | Seed data | API |
|---|---|---|---|---|
| `context/AuthContext.tsx` | `useAuth` | `trucklagbe_users`, `trucklagbe_current_user` | `data/users.ts` | `user, users, isLoaded, login, register, logout, updateUser, getUsersByRole` |
| `context/TruckContext.tsx` | `useTrucks` | `trucklagbe_trucks` | `data/data.ts` (`trucks`) | `trucks, isLoaded, addTruck, updateTruck, deleteTruck, getTruckById, updateTruckAvailability` |
| `context/DriverContext.tsx` | `useDrivers` | `trucklagbe_drivers` | `data/drivers.ts` | `drivers, isLoaded, addDriver, updateDriver, getDriverById, updateDriverStatus, updateDriverAvailability, deleteDriver` |
| `context/BookingContext.tsx` | `useBookings` (+ alias `useBooking`) | `trucklagbe_bookings` | none (empty array) | `bookings, isLoaded, addBooking, getBookingById, updateBookingStatus, updateBooking, deleteBooking, cancelBooking` |

Common pattern in every context (**keep this pattern when adding new ones**):
1. `useState(seedData)` + `isLoaded` flag.
2. `useEffect(load from localStorage, [])` → try/catch JSON.parse → `setIsLoaded(true)`.
3. `useEffect(save to localStorage, [state, isLoaded])` guarded by `if (!isLoaded) return;`
4. Custom hook throws `"useX must be used inside XProvider"` when context is undefined.
5. Updater functions use `setX(previousX => ...)` with `.map`/`.filter` — never mutate.

`BookingContext` also **migrates legacy records on load** (fills `bookingId`,
`customerPhone`, `dropLocation`, `estimatedFare` from older field names). Keep this.

## 6. Conventions to Follow

- Files: components `PascalCase.tsx`; pages always `page.tsx`; types `types/domain.ts`; hooks `hooks/useX.ts`; contexts `context/XContext.tsx`.
- Add `"use client"` to anything using hooks/state/localStorage.
- Import via `@/` alias, never long relative paths.
- Tailwind only — no CSS modules. Brand color = **orange-500/600**, surfaces `slate-*`, mobile-first with `sm: md: lg: xl:`.
- Section header pattern used across dashboards: small uppercase `text-sm font-semibold text-orange-600` eyebrow → `text-2xl sm:text-3xl font-bold text-slate-900` title → `text-sm text-slate-500` subtitle.
- Icons from `lucide-react` with explicit `size={}`.
- Always render an `isLoaded` loading row/state before mapping context data (avoids hydration mismatch).
- Money shown as `BDT {n.toLocaleString()}`; dates via `toLocaleDateString("en-BD", ...)`.
- Tables: `overflow-x-auto` + `min-w-*` + `thead` `bg-slate-50 text-xs uppercase tracking-wide text-slate-500`.
- Status pills: green = good/available/delivered, blue = in progress, amber = pending/maintenance, red = cancelled/suspended, slate = offline.
- Adding a feature: page in `app/...` → components in `components/(admin|driver)/` → types in `types/` → wire to context → add link in the relevant Sidebar/Navbar.

## 7. Known Issues / Tech Debt (high value backlog)

1. **Duplicate Booking fields** (`id`/`bookingId`, `phone`/`customerPhone`, `deliveryLocation`/`dropLocation`, `totalPrice`/`estimatedFare`) — plan a single migration to canonical names, then drop aliases and the load-time migration.
2. **Redundant BookingStatus values**: `"Driver Assigned"` vs `"Assigned"`, plus `"Completed"` is filtered for in `admin/page.tsx` but is **not** in the union. Normalize the status machine.
3. **Contexts are not used everywhere.** `admin/users/page.tsx` and `admin/drivers/page.tsx` have their own hardcoded arrays instead of `useAuth().getUsersByRole("customer")` / `useDrivers()`. `admin/trucks/page.tsx` keeps fleet status in local state (not persisted). Migrating these is the single biggest cleanup win.
4. **Two competing driver-application stores**: pages write `localStorage["trucklagbe-driver-applications"]` (hyphens) and `localStorage["trucklagbe-customer"]`, while contexts use `trucklagbe_*` (underscores). Unify on `trucklagbe_*` and route applications through `DriverContext`.
5. **Truck images** point to `/trucks/*.jpg` but `public/` only has `images/` + svgs → broken images. Either add assets or repoint paths.
6. **No route protection / role guards.** `/admin` and `/driver` are publicly reachable; `AuthContext` isn't consulted. Passwords are plaintext in localStorage (demo only — never ship).
7. **Several files are single-line minified-style JSX** (`admin/users`, `admin/drivers`, `admin/trucks`, `admin/bookings`, `driver/trips`, `driver/register`, `register/customer`, `login`). Hard to diff/edit; format them with Prettier before editing heavily.
8. `Success` component is exported from `app/register/page.tsx` and imported by `driver/register` — should move to `components/`.
9. Driver earnings hardcode a 78% commission (`estimatedFare * 0.78`) in the UI — extract to a shared constant/util.
10. No tests, no `.env`, no API layer, no `Navbar` in the root layout.

## 10. Debug Cheatsheet

| Symptom | Fix |
|---|---|
| `useX must be used inside XProvider` | component isn't under `app/layout.tsx` tree or missing `"use client"` |
| Hydration mismatch | reading localStorage during render — move into `useEffect`, gate on `isLoaded` |
| Data resets on reload | save `useEffect` ran before load finished — keep the `if (!isLoaded) return;` guard |
| Dev server broken | `cd frontend; rmdir /s /q .next; npm run dev` (PowerShell: `Remove-Item -Recurse -Force .next`) |
| Deps corrupted | delete `node_modules` + `package-lock.json`, `npm install` |
| 404 on a route | must be `app/<route>/page.tsx`, dynamic = `[id]/page.tsx` |
